Auspice version 3 (September 2026) and v3.1 (October 2026) introduced some major changes to how we render the map.
This post will dive into the differences, as well as details for how to update any custom Auspice instances you may be running.
Alongside the map changes there were a number of internal changes which you can read about via the release notes: [3.0.0](https://github.com/nextstrain/auspice/releases/tag/v3.0.0) and [3.1.0](https://github.com/nextstrain/auspice/releases/tag/v3.1.0).


> Auspice v3 is our first major release in almost 7 years, despite over 70 feature releases!
  This reflects our focus on keeping the interface for consuming projects as stable as possible.
  The change in map tile provider (described below) necessitated a major version bump as custom Auspice builds which configure the map will need to change.

## Vector map tiles via OpenFreeMap

We now use [vector map tiles](https://en.wikipedia.org/wiki/Tiled_web_map) which are rendered in the browser.
These have a number of advantages over our previous approach of rasterised tiles.
The most noticeable from a user-perspective will be the increased sharpness of the tiles, which is maintained during zooming.
Loading times are also marginally improved as the tiles themselves are smaller, and browser caching of tiles is now allowed.

Our **map styling** has always been heavily customised in order to present a desaturated and unobtrusive looking map where the overlaid (colourful) demes and transmission lines stand out.
We previously used (rasterised) tiles from MapBox, where the styling was applied on the MapBox side.
The shift to vectorised tiles via OpenFreeMap means the styles are now applied by the browser using our own [custom MapLibre Style JSON](https://github.com/nextstrain/auspice/blob/master/src/util/map-styles.json), which is based on [the OpenMapTiles positron theme](https://openmaptiles.org/styles/positron/).

## Legend UI changes

The map legend now shows how many tips different deme (circle) sizes represent ([@fig:map-h3n2],[@fig:map-hover]).

Hovering on a deme (circle) also shows you the deme name (e.g. which region, country, division) and the number of currently visible tips.
If the current coloring is categorical, and thus the deme is rendered as a pie chart, we also show how many tips are behind the currently hovered arc.
The previous behavior of highlighting matching tips on the tree (for the entire deme) remains unchanged. 

There have also been changes to the rendering of color-by swatches in the legends ([@fig:map-h3n2]), including the ability to render as a single column and to allow scrolling within the legend when the number of swatches grows large.

## User map customisations need updating

A custom Auspice build can configure the map tile provider, which was previously necessary as the cost of our MapBox tiles meant we couldn't allow custom Auspice instances to use them (except for local use).
The new default settings (OpenMapTiles) don't carry these restrictions and so are usable out-of-the-box for custom Auspice builds.
If you wish to customise the map by providing your own MapLibre style JSON then [our customise-client docs](https://docs.nextstrain.org/projects/auspice/en/stable/customise-client/api.html#custom-map-tiles) have been updated with full details of how to do this, including links to working examples in the Auspice repo.

To be clear, previous customisations which worked with Auspice v2 will no longer work with Auspice v3, and it was this breaking change which necessitated a major version release.
    

## Future directions: offline use

We intend to improve the ability to use Nextstrain tools offline, or with limited internet connections, and the change in tile provider makes this possible.

We recently [allowed service workers](https://github.com/nextstrain/auspice/pull/2062) to allow [auspice.us](https://auspice.us) to be accessible without an internet connection by leveraging the browsers cache.
We can allow the service worker to serve tiles which exist in the browser cache which would allow offline access for areas of the map you've recently explored.
This could be coupled with pre-fetching of tiles from other zoom levels when the user is online.

For local Auspice installs (e.g. `nextstrain view` or `auspice view`) we could fetch map tiles from low zoom levels & bundle them with the app so that the app works entirely offline, so long as you don't zoom in too far.
The small size of vector tiles makes downloading / bundling the tiles feasible.
